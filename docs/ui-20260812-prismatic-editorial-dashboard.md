# 弹幕看板棱镜编辑风重设计方案

## 项目设计语言映射表

| 项目 | 现状 | 本次处理 |
| --- | --- | --- |
| 样式系统 | `tokens.css`集中管理颜色、字号、间距、圆角和动效 | 沿用变量体系，替换视觉值并补充光谱角色 |
| 页面结构 | 顶栏、导航、采集控制、左弹幕、右看板、历史双栏 | 功能和区域不变，重新安排留白与分隔方式 |
| 字体 | 中文系统无衬线加等宽数据字体 | 中文控件继续使用系统无衬线，等宽字体只保留时间和数值 |
| 色彩 | 黑绿科技界面，青色与绿色分散强调 | 改为唱片黑、石墨、暖灰白；光谱只成组出现 |
| 面板 | 大量描边卡片和网格背景 | 改为平面区域、共享分隔线和低对比明度层级 |
| 动效 | 状态呼吸、按钮反馈、浮层出现 | 保留状态反馈，去掉装饰性发光，遵守减少动态效果设置 |

## 信息层级方案

1. 第一层级：实时弹幕正文、采集状态、弹幕总数。使用`--color-text`和标题、重点数值阶梯。
2. 第二层级：房间输入、开始与停止、最近一分钟、活跃人数、趋势。使用`--color-text`与`--color-text-muted`。
3. 第三层级：平台能力说明、历史元信息、时间戳、存储位置。使用`--color-text-muted`与`--color-text-faint`。

## 布局结构

```text
┌ 棱镜品牌 ───────── 房间与时长 ───── 状态 ┐
├ 实时 / 历史 ─── 连续光谱选中线 ─────────┤
├ 平台与直播间输入 ─────────── 开始采集 ──┤
├──────────────────┬──────────────────────┤
│ 实时弹幕          │ 现场概览             │
│ 大棱镜空状态/列表 │ 统计矩阵             │
│                  │ 光谱趋势             │
│                  │ 高频词 / 活跃用户    │
└──────────────────┴──────────────────────┘
```

- 宽窗口沿用双栏，弹幕区约占六成。
- 760px以下显示弹幕与看板页签；520px以下统计矩阵改单列。
- 装饰棱镜只在空状态中央出现，文字位于图形下方并留出独立占位。

## 组件规格清单

| 组件 | 类型 | 视觉规格与状态 |
| --- | --- | --- |
| 棱镜品牌标记 | 新增公共图形 | SVG单线入射、空心三角形、六道平行光谱；无交互 |
| 主导航 | 既有组件改款 | 默认弱文字；hover提升明度；active使用1px连续光谱底线；disabled沿用原生语义 |
| 平台切换 | 既有组件改款 | 石墨底；选中项使用暖灰白底；键盘左右方向键保持不变 |
| 主要按钮 | 既有组件改款 | 暖灰白底、唱片黑文字；hover提亮；active下移1px；disabled降低对比度但仍可读 |
| 输入框 | 既有组件改款 | 石墨底和细边线；focus边线变亮；错误同时显示错误文字 |
| 统计矩阵 | 既有组件改款 | 共享分隔线，不再使用六张独立发光卡片；长数值省略并保留语义文本 |
| 趋势图 | 既有组件改款 | 柱状数据按光谱顺序循环；缺口使用危险色虚线，不能只靠颜色识别 |
| 弹幕列表 | 既有组件改款 | 用户名回归中性色；hover只增加一层石墨背景；正文允许任意换行 |
| 历史列表 | 既有组件改款 | 选中项使用浅层石墨背景与1px光谱顶线；元信息保持截断 |
| 删除确认 | 既有组件改款 | 唯一有明显阴影的浮层；危险图标、标题和按钮共同表达不可恢复 |

## 交互与动效规范

- hover与focus使用`--transition-fast`，面板切换使用`--transition-standard`。
- 光谱图形不做持续移动。采集状态仅保留克制的透明度呼吸。
- 空状态不做编排式入场。新消息按钮继续承担回到最新的状态反馈。
- `prefers-reduced-motion`下所有过渡压缩到最短时间。

## 设计依据

- 用户要求减少科幻感，并采用类似月之暗面所代表的棱镜折射、黑色留白和唱片封套艺术感。
- `impeccable`的Operate模式要求标准控件、信息扫读和状态清晰优先。
- 中文排版使用系统中文无衬线字体，禁止伪斜体、负字距和装饰图形压字。
- 色彩策略为Restrained加单一光谱签名。光谱是一个连续对象，不作为多组独立强调色散布。

## 待决策项

- 当前没有用户提供的正式品牌Logo，因此棱镜是界面签名而不是注册商标。
- 当前不引入中文网络字体，避免安装包增加数MB资源；艺术感由构图和图形承担。

## 给code-writer的交付说明

- 需要修改`tokens.css`、`app.tsx`并新增独立主题样式，业务状态和IPC接口不得变化。
- 复用现有布局类名、响应式断点、按钮、输入、页签、列表和对话框。
- 新增`PrismArtwork`组件，尺寸通过variant控制，颜色从CSS变量读取。
- 需要保留键盘焦点、ARIA关系、减少动态效果和窄窗口单页推进。
- 反套路检查：移除网格、霓虹光晕、英文科技眉题、独立发光指标卡和散落强调色。
- 中文页面实现时同时遵守`rules/cn_typography.md`。

# 实时监控界面规格

版本：`v1`

日期：2026-07-29

## 选择

正式实现采用原型方案A：

- 宽窗口左侧显示实时弹幕，右侧显示实时看板。
- 方案B的大字号弹幕密度用于优化消息可读性。
- 方案C的带状数据缺口标记用于趋势图。
- 窄窗口不纵向堆叠两个长页面，改为弹幕与看板页签。

原型见[实时监控界面原型](../prototypes/realtime-monitor/README.md)。

## 视觉方向

界面采用棱镜编辑风的深色信息版面：

- 背景以哑光近黑与石墨色为主，减少长时间观看疲劳。
- 原创棱镜与连续光谱用于品牌、空状态、导航选中线和趋势基线，不复刻具体专辑封面或标志。
- 采集、警告、数据缺口和删除使用独立语义色，不借用光谱颜色的装饰含义。
- 状态同时使用文字和图形，不能只靠颜色。
- 中文正文使用macOS系统字体栈，时间与数值使用等宽数字。
- 大区域使用细分隔线和留白区分，不使用网格背景、霓虹外发光、玻璃卡片或HUD标签。

## 窗口

- 默认窗口：`1280 × 820`。
- 最小窗口：`620 × 640`。
- `760px`及以上使用左右并列布局。
- 小于`760px`使用弹幕与看板页签。
- 窗口关闭后隐藏到菜单栏，采集状态不变化。
- 再次打开时恢复上次窗口尺寸、位置、主导航和窄窗口页签。
- 不保存弹幕滚动位置，重新打开时回到最新消息。

## 全局结构

### 顶栏

始终显示：

- 应用或房间标题。
- 真实房间号。
- 采集时长。
- 实时与历史主导航。
- 文字化采集状态。
- 菜单栏状态入口。

状态文案：

| 内部状态 | 界面文字 |
| --- | --- |
| `idle` | 未开始 |
| `resolving_room` | 正在检查房间 |
| `waiting_for_live` | 等待开播 |
| `connecting` | 正在连接 |
| `collecting` | 正在采集 |
| `recovering` | 连接恢复中 |
| `risk_blocked` | 匿名访问受限 |
| `start_failed` | 启动失败 |
| `stopping` | 正在停止 |

### 状态横幅

只有需要用户留意的状态显示横幅：

- 等待开播：房间尚未开播、下次检查时间、停止等待。
- 连接恢复：数据缺口开始时间、尝试次数、下次重试时间、立即重试、停止。
- 匿名访问受限：已有数据保留位置、下次重试时间、立即重试、停止。
- 存储故障：无法写入本地资料库、积压数量、存储检查和停止。
- 启动失败：脱敏原因、重试和修改房间。

正常采集只使用紧凑状态行，不长期占用告警横幅。

## 未开始

实时页在`idle`状态显示单一开始入口：

- 可见标签：直播间号或直播链接。
- 输入支持纯房间号和`live.bilibili.com`链接。
- 主按钮：开始采集。
- 明确说明匿名采集、不需要Cookie、数据只保存在本机。
- 明确说明未开播会进入等待，首次鉴权前不会生成历史会话。

输入校验在提交或失焦后出现，不能逐字符报错。错误文字显示在字段下方：

- 请输入直播间号或直播链接。
- 只支持B站直播链接。
- 未找到这个直播间。

## 实时页宽窗口

### 左侧实时弹幕

- 宽度约占工作区`57%`。
- 列顺序为接收时间、展示昵称、弹幕正文。
- 粉丝牌作为正文前的紧凑标签。
- 列表按接收时间升序，新消息出现在底部。
- 渲染进程最多保留500条弹幕DOM节点。
- 用户位于列表底部时自动跟随新消息。
- 用户向上滚动后停止自动跟随，并显示有新消息的悬浮按钮。
- 点击悬浮按钮回到底部并恢复自动跟随。
- 长昵称单行截断，长弹幕允许换行，不能造成横向滚动。
- 礼物和醒目留言不混入普通弹幕列表，分别在看板统计和历史详情中查看。

状态：

- 等待开播：保留列表框架，显示等待开播空状态。
- 初次连接：显示正在连接，不伪造弹幕骨架。
- 连接恢复：保留已有弹幕，列表顶部显示缺口开始标记。
- 匿名访问受限：保留已有弹幕，不清空计数。
- 存储故障：停止增加新弹幕，显示本地写入失败状态。

### 右侧实时看板

首屏指标：

1. 当前热度与峰值热度。
2. 当前弹幕速率。
3. 弹幕总数与活跃发言人数。
4. 礼物数量、已知礼物价值、醒目留言数量与价值。

趋势：

- 显示最近30分钟弹幕数量。
- 横轴使用10秒统计桶，最多180个点。
- 数据缺口使用带边框的珊瑚红区间覆盖。
- 缺少数据的桶不绘制为零。
- 图例明确区分弹幕趋势与数据缺口。
- 鼠标悬停显示时间、弹幕数和缺口状态。

列表：

- 高频词显示前10项，默认首屏展示5项。
- 高频词来自固定容量近似计数，不显示虚假精确百分比；需要展示次数时使用约前缀。
- 活跃用户显示前10项，默认首屏展示5项。
- 活跃用户按普通弹幕数量排序。
- 无本地用户标识的弹幕不进入活跃用户人数和排行。

### 指标刷新

- 弹幕列表以批次追加。
- 数字指标每250毫秒最多更新一次。
- 趋势、高频词和活跃用户每1秒最多更新一次。
- 数值变化不使用跳动缩放动画。
- 页面处于后台时降低渲染更新频率，主进程采集和存储不受影响。

## 实时页窄窗口

顶栏下显示两个页签：

- 弹幕。
- 看板。

规则：

- 默认进入弹幕页签。
- 切换页签不影响采集和列表数据。
- 弹幕页签保留完整消息列表。
- 看板页签按指标、趋势、高频词、活跃用户的顺序纵向排列。
- 两个页签都能看到当前连接状态和数据缺口横幅。
- 不出现横向滚动。
- 所有可点击目标至少`44 × 44px`。

## 历史页

### 历史列表

- 左侧显示历史会话，右侧显示选中会话详情。
- 窄窗口先显示历史列表，选择后进入详情，并提供明确返回。
- 每项显示房间标题、开始时间、采集时长和结束状态。
- 每页50场，滚动到底继续加载。
- 活动会话不进入历史列表。
- 已逻辑删除的会话立即从列表消失。

空状态：

- 标题：还没有历史会话。
- 正文：完成一次采集后，本场数据会显示在这里。
- 操作：返回实时页。

### 会话详情

顶部显示：

- 房间标题和房间号。
- 开始与结束时间。
- 采集时长。
- 正常结束或异常中断。
- 删除整场。

摘要显示：

- 弹幕总数。
- 活跃发言人数。
- 礼物数量和已知价值。
- 醒目留言数量和价值。
- 峰值热度。
- 数据缺口数量和累计时长。

记录区域：

- 默认显示最近100条弹幕。
- 支持搜索本场弹幕正文和展示昵称。
- 搜索结果按接收时间倒序。
- 每次继续加载100条。
- 礼物和醒目留言使用独立页签，不制作跨类型回放时间线。

### 数据缺口

只要会话有缺口，摘要下方显示缺口提示：

- 每个缺口的开始、结束和时长。
- 是否恢复。
- 脱敏原因类别。
- 明确说明该区间没有可靠事件，不能解释为零互动。

### 删除整场

删除按钮使用危险色，点击后显示确认框。确认框必须包含：

- 房间标题。
- 会话日期。
- 将删除的内容。
- 开始后不能撤销。

确认后：

- 按钮进入正在删除状态。
- 会话立即从历史列表隐藏。
- 物理清理在后台继续。
- 如果当前正在查看被删除会话，返回历史列表。

## 菜单栏

菜单栏图标始终存在，点击后显示：

- 当前状态。
- 房间标题和房间号。
- 采集时长。
- 最后收到消息时间或下次重试时间。
- 显示窗口。
- 停止采集或停止等待。
- 导出诊断摘要。
- 退出应用。

采集中点击退出应用需要确认结束当前采集会话。关闭窗口不显示确认框，只隐藏窗口。
导出诊断摘要由主进程打开系统保存对话框，只写入脱敏JSON，不自动上传。

菜单栏图标状态：

- 正常采集：实心状态点。
- 等待开播：空心状态点。
- 连接恢复或匿名访问受限：带感叹标记。
- 未开始：普通应用图标。

图标变化同时有菜单文字，不能只靠图形表达状态。

## 确认框

### 停止采集

- 标题：停止本次采集？
- 正文：`{房间标题}`将停止采集，已接收数据会保存在历史会话中。
- 主操作：停止采集。
- 次操作：取消。

### 停止等待

- 标题：停止等待开播？
- 正文：`{房间标题}`将停止等待，本次不会生成历史会话。
- 主操作：停止等待。
- 次操作：取消。

### 删除历史

- 标题：删除整场历史？
- 正文：将删除`{日期}`的`{房间标题}`，包括本场弹幕、礼物、醒目留言和会话摘要。开始后不能撤销。
- 主操作：删除整场。
- 次操作：取消。

### 退出应用

- 标题：退出并停止采集？
- 正文：`{房间标题}`将停止采集，已接收数据会保存在历史会话中。
- 主操作：退出应用。
- 次操作：取消。

## 可访问性

- 正文对比度至少`4.5:1`，大字至少`3:1`。
- 键盘焦点环始终可见。
- 主导航、窄窗口页签、弹幕列表和确认框使用语义化元素。
- 状态更新通过克制的`aria-live`区域播报。
- 图表提供文本摘要和可键盘访问的数据点。
- 尊重`prefers-reduced-motion`。
- 状态切换动画保持在150至250毫秒。
- 不自动聚焦新弹幕，避免打断键盘和辅助技术用户。

## 原型验证结果

已验证：

- 方案A、B、C在`1440px`和`390px`宽度下没有横向溢出。
- 三种方案都能显示12条合成弹幕，没有脚本错误。
- 键盘左右方向键可以切换方案。
- 窄窗口弹幕与看板页签可以切换。
- 实时与历史主导航可以切换。
- 窄窗口历史页先显示列表，选择会话后进入详情，并可以返回列表。
- 删除整场会打开包含后果说明的确认框。
- 等待开播、连接恢复、匿名访问受限和未开始场景可以通过原型控制器检查。
- 窄窗口生产界面的可点击目标不小于`44 × 44px`。

原型不验证真实数据、数据库、Electron窗口或菜单栏API。正式实现不能直接复制原型代码。

# 弹幕看板v0.1.0

这是首个面向公开使用的桌面发行版，支持Apple Silicon Mac和Windows 10/11 x64。程序匿名连接B站或抖音公开直播间，在本机实时显示、聚合并保存弹幕数据。

## 下载哪个文件

- Apple Silicon Mac：`弹幕看板-0.1.0-arm64.dmg`
- Windows 10/11 x64：`弹幕看板-win32-x64-0.1.0.zip`

Windows版是便携版。请完整解压ZIP，再运行目录中的`弹幕看板.exe`，不要直接在压缩包内启动。当前macOS与Windows发行版均未购买商业代码签名，系统首次打开时可能显示未知开发者或未知发布者提示。

## 主要能力

- 获取B站公开直播间普通弹幕、礼物、醒目留言、直播状态和热度。
- 获取抖音公开直播间普通弹幕；匿名协议不能稳定提供的指标明确显示为不可用。
- 实时展示弹幕总数、速率、活跃用户、30分钟趋势、高频词和活跃用户排行。
- 使用本机SQLite保存历史场次，支持分页、场内搜索和整场删除。
- 连接中断后自动恢复，并把无法保证完整性的时间段记录为数据缺口。
- 关闭主窗口后继续在macOS菜单栏或Windows系统托盘中采集。
- 不读取平台Cookie，不保存原始用户ID，不把历史数据上传到外部服务。

## 验证记录

- 24个单元测试文件，共54项测试通过。
- 1个SQLite集成测试文件，共4项测试通过。
- Apple Silicon应用、DMG、架构、签名、Fuse、asar、运行时和挂载检查通过。
- Windows x64应用在GitHub Windows Runner中完成原生打包和正式EXE运行验收。
- Windows SQLite主进程、writer Worker、reader Worker、WAL、FTS5与`safeStorage`运行时探针通过。
- Windows两万条事件smoke基准超过每秒200条发布门槛。

## 已知边界

- 同一时间最多采集一个直播间。
- 不支持Intel Mac、Windows ARM64和32位Windows。
- 当前没有商业代码签名、公证、自动更新和应用商店发布。
- 采集依赖平台公开网页协议，上游协议变化后可能需要更新适配器。
- 抖音第一版只保证普通弹幕，不把未知礼物、热度或观看人数写成零值。

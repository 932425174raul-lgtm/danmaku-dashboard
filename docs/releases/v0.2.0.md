# 弹幕看板v0.2.0

这个版本把历史场次从“可搜索的弹幕存档”升级为“可用于调整下一场直播的互动复盘”。复盘完全在本机SQLite只读Worker中生成，不上传弹幕，也不调用外部AI服务。

## 下载哪个文件

- Apple Silicon Mac：`danmaku-dashboard-0.2.0-macos-arm64.dmg`
- Windows 10/11 x64：`danmaku-dashboard-0.2.0-windows-x64.zip`

Windows版是便携版，请完整解压ZIP，再运行目录中的`弹幕看板.exe`。当前macOS与Windows发行版均没有商业代码签名，系统首次打开时可能显示未知开发者或未知发布者提示。

## 本次更新

- 直播结束后，历史详情页自动生成“直播复盘”。
- 展示整场弹幕、活跃发言人数、人均发言和数据完整性。
- 使用自适应时间格对比弹幕量与活跃发言人数趋势，12小时内5分钟一格，超长直播最多144格。
- 标出弹幕最密集时段、活跃发言人数峰值时段和前三高峰集中度。
- 统计完整文本相同的重复弹幕TOP 5，附出现次数、发言人数与首末时间。
- 根据高峰时段、重复弹幕和高峰集中度生成可回溯的调整建议，不自动推断情绪、话题或因果。
- 数据缺口会在趋势中以红色虚线显示，页面同时提醒对应数字可能被低估。
- 明确区分“活跃发言人数”与“在线观众人数”，B站直播热度也不换算成人数。

## 复盘能做什么

这个版本可以告诉你观众在哪些时段最愿意发言，哪些完整弹幕被多次复述，以及互动是否过度集中在少数时段。你可以根据给出的时间回看当时的主题、话术或互动动作，再在下一场直播中验证调整是否有效。

程序没有直播画面、声音或逐字稿，因此不会声称知道观众为什么互动，也不会把某个高峰直接归因于主播行为。

# 弹幕看板v0.4.0

这个版本把直播结束后的基础统计升级为可用于调整下一场直播的复盘页。所有结论都来自本机SQLite已保存的互动数据，不读取直播画面、声音、Cookie或账号状态。

## 下载哪个文件

- Apple Silicon Mac：`danmaku-dashboard-0.4.0-macos-arm64.dmg`
- Windows 10/11 x64：`danmaku-dashboard-0.4.0-windows-x64.zip`

Windows版是便携版，请完整解压ZIP，再运行目录中的`弹幕看板.exe`。当前macOS与Windows发行版均没有商业代码签名，系统首次打开时可能显示未知开发者或未知发布者提示。

## 本次更新

## 数据边界

分时「人数」指该时间格内发过弹幕的本机匿名去重人数，不是在线观众人数。B站热度也不会被换算成观看人数。程序不读取直播内容，因此只提供带数据依据的回看和验证方向，不自动判断观众情绪或主播行为对数据的因果关系。

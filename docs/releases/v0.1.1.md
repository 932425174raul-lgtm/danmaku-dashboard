# 弹幕看板v0.1.1

这个补丁版本提高了实时看板的色彩辨识度，macOS与Windows版本同步更新。

## 下载哪个文件

- Apple Silicon Mac：`danmaku-dashboard-0.1.1-macos-arm64.dmg`
- Windows 10/11 x64：`danmaku-dashboard-0.1.1-windows-x64.zip`

Windows版是便携版。请完整解压ZIP，再运行目录中的`弹幕看板.exe`。当前macOS与Windows发行版均未购买商业代码签名，系统首次打开时可能显示未知开发者或未知发布者提示。

## 本次更新

- 六项实时指标按红、橙、黄、绿、蓝、紫的折射顺序显示弱底色、短横线和数字颜色。
- 30分钟趋势按时间从暖色连续过渡到冷色，数据缺口继续使用红色虚线标记。
- 高频词使用暖色，活跃用户使用冷色，排行类别更容易区分。
- 保留文字标签、固定位置和缺口图例，颜色不是识别信息的唯一方式。
- 更新GitHub详情页的合成数据预览图。

## 验证记录

- 24个单元测试文件，共55项测试通过。
- 1个SQLite集成测试文件，共4项测试通过。
- 六种指标数字与对应底色的对比度均高于5:1。
- 1440px宽窗口和580px窄窗口均无横向溢出，浏览器控制台没有运行错误。
- macOS与Windows发行产物继续执行架构、Fuse、asar、SQLite运行时和性能检查。

完整安装方法、数据目录、隐私边界和自行构建步骤请查看[项目README](https://github.com/932425174raul-lgtm/danmaku-dashboard#readme)。

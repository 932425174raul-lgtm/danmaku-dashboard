# 弹幕看板v0.3.0

这个版本把实时页升级为直播过程中的趋势监控台。程序会比较前后两段互动，并同时展示5类最近30分钟趋势。全部判断只使用已经写入本机SQLite的数据，不读取直播画面、声音、Cookie或账号状态。

## 下载哪个文件

- Apple Silicon Mac：`danmaku-dashboard-0.3.0-macos-arm64.dmg`
- Windows 10/11 x64：`danmaku-dashboard-0.3.0-windows-x64.zip`

Windows版是便携版，请完整解压ZIP，再运行目录中的`弹幕看板.exe`。当前macOS与Windows发行版均没有商业代码签名，系统首次打开时可能显示未知开发者或未知发布者提示。

## 本次更新

- 实时页新增当前一段状态，区分互动升温、平稳、回落、安静、数据积累和数据缺口。
- 当前段使用最近最多5分钟，与前一段等长时间比较；前一段为零时显示新增，不显示无穷百分比。
- 新增弹幕量、活跃发言、直播热度、礼物和醒目留言5张最近30分钟趋势图。
- 趋势在主进程中按10秒记录，界面按1分钟合并，最多显示30个点。
- 每张趋势图使用固定颜色，同时显示标题、单位和当前值；数据缺口继续使用珊瑚红虚线格。
- 活跃发言人数使用固定容量的本机匿名估算，不保存整场用户集合，也不把发言人数写成在线人数。
- 抖音匿名协议没有稳定提供的热度、礼物和醒目留言在总览、当前段与趋势图中都显示为不可用。
- 宽面板中的趋势图使用两列排列，窄面板自动改为单列，620px窗口没有水平溢出。

## 状态如何判断

状态只根据弹幕量变化判断，不把不同量纲拼成没有依据的综合分数。直播开始不足2分钟时显示数据积累中；可比较后，当前段比前一段增加或减少至少25%，且绝对变化超过3条，才显示升温或回落。对比时间内有数据缺口时暂停判断。

直播热度是平台提供的热度值，不是观看人数。活跃发言人数只统计发过普通弹幕且能在本机匿名去重的人，也不是观看人数。

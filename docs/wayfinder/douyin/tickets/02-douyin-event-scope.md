## Question

在坚持匿名采集且不要求Cookie的前提下，抖音第一版应保存哪些评论、点赞、进场、关注、礼物、房间统计和开播或下播事件；协议未提供、被风控过滤或当前无法验证的指标，界面和历史记录分别如何表达不可用？

## Resolution

第一版只把普通弹幕、直播与连接状态作为业务事件；点赞、进场、关注和未知方法只用于脱敏协议诊断。礼物、醒目留言、在线人数、累计观看、平台热度与尚未验证的下播语义统一标记为事件不可用，界面显示不可用，历史模型使用`null`，不能写成零。

详细验收见[抖音第一版事件范围与不可用语义](../../../spec/douyin-event-scope.md)。
